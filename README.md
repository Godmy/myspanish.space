# Школа испанского · myspanish.space

Рабочее приложение: публичный сайт, учебный кабинет, рабочее пространство преподавателя и администратора. SvelteKit 2 / Svelte 5 / TypeScript, раздельные SQLite-базы и закрытые учебные файлы.

```powershell
yarn install --immutable
yarn dev
```

Открыть **http://localhost:5176**. Тестовые роли — **/login**, только в development. Данные сохраняются в `.school-data`. Нужен Node.js 24.11+.

**[Инструкция запуска, проверки, добавления курса, импорта и передачи проекта](docs/HANDOFF.md)**.

Проверки: `yarn check`, `yarn test`, `yarn test:e2e`. Сборка Cloudflare: `yarn build`; автономный Node-сервер: `yarn build:node`, `yarn user:create`, `yarn start:node`. Сначала создайте собственного администратора; production не включает тестовый вход и не принимает demo-базу.

Общие школьные UI: `../../stylist-svelte/modules/prototype/prototype-school`; испанская композиция, временная конфигурация и собственный демоконтент: `../../stylist-svelte/modules/business/spanish`. Сборка исходников требует соседней библиотеки; используется Yarn portal.

Реальный учебный архив не найден и не прочитан. Импортёр проверен на собственных fixtures. Контакты, сведения о преподавателе, цены, расписание, права и юридические документы ожидают подтверждения владельца. Внешние почта, оплата и хранилище не подключены; их успешная работа не имитируется.
