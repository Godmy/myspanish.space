# Постоянный preview

Обновление 30.10.2026: подключён каталог реальных учебных метаданных; учётные записи по-прежнему демонстрационные. Состав, исключение персональных записей и команды импорта описаны в [ARCHIVE-DATA.md](ARCHIVE-DATA.md). Указания ниже о полностью синтетическом содержимом относятся к первоначальной версии preview.

Адрес: https://myspanish-school-preview.pavarenkinda.workers.dev

Работает на Cloudflare независимо от локального компьютера. Главная, документы, форма заявки и остальные публичные страницы открываются сразу. Страницы «Закрытый preview» с запросом общего пароля больше нет. `/login` показывает обычный вход по данным, предоставленным школой; демонстрационные роли скрыты и их отправка без специального разрешения запрещена на сервере.

Существующее разрешение на демонстрационные роли используется только внутренними проверками через POST `/__preview/login`; GET этого адреса перенаправляет на главную. Секрет `PREVIEW_ACCESS_KEY` и локальный `.preview.local/access-key.txt` не нужны посетителям лендинга и не передаются в Git.

## Оформление «Испанский полдень»

Схема `spanish` зарегистрирована в общей дизайн-системе: `stylist-svelte/modules/design-system/theme/const/record/scheme-spanish/index.ts`. В `theme/component/organism/theme-palette/index.story.ts` добавлен одноимённый preset. Генерируемые barrel-файлы вручную не менялись; их обновляет владелец индексатором при очередной генерации библиотеки. Приложение использует прямые логические импорты.

Сайт выбирает схему в `src/routes/+layout.svelte`. CSS-переменные присутствуют уже в серверном HTML, а ThemeProvider поддерживает их после гидрации. Школьная композиция и адаптивная типографика — `src/school.css`: основной текст 18 px, плотные заголовки, крупные элементы управления. Шрифт Golos Text поддерживает русский и испанский; при отсутствии Google Fonts используется Segoe UI/system sans-serif.

Адаптивность публичных страниц проверяется на 360, 390, 768, 1024 и 1440 px; кабинеты ученика, родителя, преподавателя и администратора — на 360, 768 и 1440 px. Проверка входит в `yarn test:e2e`; снимки сохраняются в игнорируемом `test-results/branding`.

Preview предназначен для проверки сайта на синтетических данных. Публичным посетителям доступен обычный вход, выбор демонстрационного администратора им недоступен. Не загружайте реальные персональные данные, работы учеников и закрытые издательские материалы.

## Архитектура и повторная публикация

Подготовка 09.11.2026: лендинг «Испанский для всех», фотография Марины, форма записи и четыре документа школы включены в исходники. Подпись «Испанский с Мариной · онлайн» над главным заголовком удалена. Реквизиты и документы остаются на согласовании; для preview это не блокирует просмотр.

`yarn build:preview` собирает Cloudflare-приложение в отдельный игнорируемый каталог `.svelte-kit-school-preview`. Сборочная конфигурация `wrangler.build-preview.jsonc` задаёт выход адаптера SvelteKit; она не предназначена для публикации. Полученный `cloudflare/_worker.js` используется `cloudflare/preview-entry.ts`, а весь `cloudflare` с `.assetsignore` — как каталог assets в `wrangler.preview.jsonc`. Локальный Vite продолжает работать с `.svelte-kit-school`. Команда не пересобирает `stylist-svelte/dist` и не обращается к удалённой базе.

Проверка готовности из корня workspace:

```powershell
yarn --cwd myspanish.space/myspanish.space check
yarn --cwd myspanish.space/myspanish.space test:preview
yarn --cwd myspanish.space/myspanish.space build:preview
yarn --cwd myspanish.space/myspanish.space check:worker
```

Публикацию выполняет владелец: `yarn --cwd myspanish.space/myspanish.space deploy:preview`. После публикации — `yarn --cwd myspanish.space/myspanish.space test:preview:remote` и проверка главной, четырёх документов и тестовой заявки. Сохранённые настройки удалённого стенда имеют приоритет над исходными значениями: название должно быть «Испанский для всех»; при необходимости оно меняется через `/staff/settings`. Локальные настройки и база автоматически не переносятся. Пароль, экземпляр Durable Object и его данные сохраняются; реальные контакты в preview не используются.

Отдельный Worker `myspanish-school-preview`, отдельный SQLite Durable Object `SchoolPreview`, экземпляр `school-v1`. Исходные миграции преобразованы в `cloudflare/preview-schema.sql`; локальные базы не копировались. Вложения хранятся частями в SQLite. Основной домен, D1 и production-конфигурация не менялись.

Из каталога приложения:

```powershell
yarn check
yarn check:worker
yarn test:preview
yarn deploy:preview
```

Использовать только `wrangler.preview.jsonc` для preview. Повторная публикация сохраняет DO-данные и секрет. После изменения локальной схемы нужен отдельный план миграции существующего DO; генерация финальной схемы сама по себе не обновляет существующие столбцы.

## Ограничения

Это общий демонстрационный стенд с сохраняемыми изменениями. Почта, оплата и видеовстречи не подключены. Физический архив в Cloudflare не переносился: импорт реестра сохраняет метаданные; отсутствующие вложения остаются недоступными. Производственный вход по индивидуальным паролям проверен для Node-варианта; в preview обычный вход работает через логин и пароль, а выбор тестовых ролей требует отдельного внутреннего разрешения. Это не production-развёртывание для реальных учеников.
