# Первый полный курс и проверка наполнения

## Войти и скачать

Сайт запускает Дмитрий командой `yarn myspanish` из `D:/2026/cloudflare`. Адрес — `http://localhost:5176`.

- `/login` → «Администратор»: служебная библиотека, архив и любые подключённые файлы, включая технические записи.
- `/login` → «Аня · демо» (роль ученика): три исходных демоурока и подготовленный осенний курс. Логин/пароль для выбора локальной роли не требуются; это отдельная карточка под формой обычного входа.
- `/account/courses/pack:autumn` → пять уроков; первый: `/account/lessons/pack:autumn:lesson-1`.
- `/staff/library` и `/staff/archive` → каталог для сотрудников. В карточке «Происхождение и файл» есть скачивание.

Закрытый файл без действующей школьной сессии теперь перенаправляет на `/login?next=…`; после входа браузер возвращается к запрошенному файлу. Сохраняется и параметр `child`. Вошедший пользователь без назначения курса по-прежнему не получает файл (404). Используйте один хост (`localhost`), один браузер и тот же профиль: сессия `127.0.0.1` не является сессией `localhost`. Упомянутый `E3dc63480b260` — служебный `.DS_Store`; преподавателю он закрыт, администратору доступен. На работающем сайте проверено: после входа администратором скачивание этого ID и изображения `E6e04561c79fc` возвращает 200.

## Пять осенних занятий

Курс сохранён под прежним ID `pack:autumn` и адресом программы `/directions/pack-autumn`. Пять уроков: листья; дождь, зонтик и сапоги; ёжик из шишки; наблюдение за изменениями; фигуры и итоговая игра.

Внутри: цели, подготовка, разговорный пример, 30 испанских реплик с переводами, действия по шагам, наблюдаемая проверка понимания, варианты адаптации и домашние задания. 31 упражнение охватывает карточки, один ответ, несколько ответов, пары, пропуски, порядок слов и свободный текст. Дополнительно созданы пять скачиваемых текстовых памяток. К каждому уроку подключены руководство и распечатки PDF.

Это вводный тематический курс для совместной игры ребёнка и взрослого. Весь основной сценарий можно пройти без исходных песен и видео. Обещание уровня CEFR или проверки произношения не заявляется. Источники и методические замечания сохраняются в скрытых заметках преподавателя.

Курс и уроки включены для локальной проверки и назначены существующему тестовому ученику `student`. Другой ученик `student-b` остаётся проверкой отсутствующего доступа. Учебные материалы разрешены только внутри назначенного курса; открытая выдача этих PDF и памяток не включена. Существующая история обучения не очищается.

## Описания фонда

У всех 4730 зарегистрированных записей архива заполнено описание. 496 существующих аннотаций сохранены, 4234 подготовлены:

- 1779 — по сохранённым извлечённым фрагментам;
- 145 — по машинному OCR с явной пометкой;
- 2288 — по названию и месту в каталоге;
- 22 — описания служебных файлов.

Источник аннотации записан в `description_source`. Аннотация по названию не означает просмотр видео или прослушивание аудио; OCR не становится редакторской проверкой. Глобальные статусы проверки, права и публикация материалов не повышаются. Новые пять учебных памяток описаны отдельно.

Служебные маркеры RECORD/PAGE и шаблонные подписи PowerPoint исключаются из новых текстовых фрагментов. Проверяется хеш выбранного дополнительного извлечения. При обновлении автоматически созданного описания скрипт сравнивает его с прежним текстом и сохраняет последующие ручные правки.

## Публичные страницы

Подготовлены главная, описание курса, информация о подходе Марины, FAQ, объяснение учебного кабинета и форма связи. Готовая программа выводится перед остальными недемонстрационными направлениями.

Использованы контекст проекта и материалы автора о совместных занятиях. Не публикуются неподтверждённые сведения об образовании, стаже, числе учеников, текущих ценах и старые рекламные контакты. У владельца запрошены актуальное имя/фамилия для сайта, биография, контакт для записи, форматы, цены и сведения о владельце для документов. Страницы условий и политики остаются черновиками до получения этих сведений.

## Повторное применение

Из каталога приложения:

```powershell
$env:PYTHONUTF8 = '1'
python scripts/school/prepare-material-descriptions.py
node --experimental-strip-types scripts/school/prepare-first-course.ts
```

Для обновления именно ранее созданных каталожных аннотаций у Python-скрипта есть `--refresh-generated`. Исходный курс хранится в `scripts/school/content/autumn-course.json`, публичные тексты — в `public-pages.json`. Пустые контакты из пакета не стирают уже заполненные настройки. Неизменная ревизия курса повторно не перезаписывает ручные правки уроков. Резервные копии всех трёх баз создаются в `.school-data/content-backups`; закрытые подготовленные аннотации и результат применения остаются в `.school-data`.

## Проверено

Изолированный сквозной тест проверил все 31 упражнение: для 21 автоматически проверяемого задания проверены правильные ключи, карточки и свободный ответ не выдаются за автоматическую оценку. Тест скачал материалы ученика, отправил домашнее задание, проверил отсутствие ключей и скрытых заметок в ученическом DTO и отсутствие доступа другого ученика. Повторное применение сохранило ручную правку урока и отправленный ответ.

Итоговые 30 тестов архива, preview, школы и полного курса прошли; точечная проверка TypeScript и компиляция изменённых Svelte-компонентов прошли. На сервере, запущенном владельцем, выполнены HTTP-проверки публичных страниц, ученического курса, первого урока, памятки и частичного скачивания PDF (206). Сервер агент не запускал; визуальная проверка и прохождение владельцем остаются следующим этапом. Сборка и деплой не выполнялись; генерация экспортов и манифеста не требуется.

## Исправление перехода к скачиванию после входа

Раньше отсутствие или истечение школьной сессии давало ту же ошибку 404, что отсутствие доступа. Теперь локальная ссылка на закрытый файл сначала открывает страницу входа, а затем возвращает к тому же скачиванию. Публичный демофайл остаётся доступен без входа. Адрес возврата ограничен `/api/school/files/<ID>`; внешний адрес, другая страница или небезопасный идентификатор не допускаются.

Проверено в отдельном Chrome нажатием настоящих кнопок ролей и событием фактического скачивания: администратор, ученик и родитель получают памятку `pack:autumn:lesson-1:handout` с `child=student` и без него. Администратор получает и технический `.DS_Store`, ученик и родитель — нет. Истёкшая/недействительная сессия ведёт на вход; другой ученик без курса остаётся без доступа. Четыре браузерных сценария и пять модульных проверок прошли.

Повтор проверки на уже работающем сайте:

```powershell
$env:SCHOOL_BROWSER_BASE_URL = 'http://localhost:5176'
yarn exec playwright test tests/browser/download-access.spec.ts --output=.school-data/download-qa --reporter=list
node --experimental-strip-types --test tests/file-return.test.ts tests/local-download.test.ts
```

Тест не запускает сервер и не использует личный профиль браузера владельца. Cookie и пароли не выводятся.
