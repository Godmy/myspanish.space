Ранее созданный собственный демомодуль остаётся доступен.

## Локальный импорт

Из каталога приложения:

```powershell
yarn archive:export
yarn archive:apply
yarn test:preview
```

Экспортёр принимает `--source` и `--output`. По умолчанию создаёт игнорируемую `.school-import`: JSON-порции, manifest и отчёт. Эти файлы содержат закрытые метаданные и не входят в Git или статические ресурсы сайта. Для другой локальной базы задаётся `SCHOOL_DATA_DIR`. CLI рассчитан на development-базу с существующим администратором.

Миграция `010_archive.sql` добавляет таблицы каталога к существующей модели. Импорт не заменяет пользователей, сессии, назначения, ответы, проверки или редакторские изменения. Порции атомарны, имеют контрольную сумму; повтор не создаёт дублей. Изменённая порция с тем же идентификатором отклоняется. Новые снимки добавляются, а не автоматически перезаписывают отредактированные записи.

## Обновление preview

```powershell
yarn build
yarn exec wrangler deploy --config wrangler.preview.jsonc
node scripts/school/prepare-preview-import.mjs
curl.exe --silent --show-error --config .school-import/gate.curl
curl.exe --silent --show-error --config .school-import/login.curl
curl.exe --fail-early --silent --show-error --config .school-import/upload.curl
```

Два входа должны вернуть 303; все порции — 200. `/api/school/archive` требует сессию администратора и проверяет Origin. После обновления доступен `/staff/archive`, поиск — `/staff/library`, программы — `/staff/courses`. Черновики занятий открываются из редактора курса через предварительный просмотр. Родитель и ученик не получают доступ к архиву.

`gate.curl` и cookie-файл содержат данные входа: оставлять их только в игнорируемой папке, после загрузки удалить. Для повторного импорта их можно создать заново. Без ключей внешних сервисов письма, оплаты и файлы не имитируются.

## Проверки

Тесты проверяют полный пакет через preview SQL-адаптер, повторный импорт, сохранение существующего ответа и редакторской правки, отдельность NFC/NFD-путей, закрытые материалы, административный импорт и отсутствие автоматического доступа к черновым урокам. Браузерная проверка реальных данных охватывает архив, поиск, происхождение материала, подготовленный урок и направления на ширинах 360/768/1440.
